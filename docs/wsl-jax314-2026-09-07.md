# Python 3.14 JAX environment — PhilipSecond

The user requested `~/.virtualenvs/jax314` with the same libraries as `jax`.
It uses standard CPython 3.14.7 managed by uv, without Conda. Activate with:

```bash
source ~/.virtualenvs/jax314/bin/activate
```

The default `py313` environment remains unchanged. Package versions and local
editable project paths are copied from the current `jax` environment.

## Required differences

TensorFlow 2.21.0 publishes wheels through CPython 3.13, but none for CPython
3.14. TensorFlow, TF-Keras and GPflow are therefore omitted from `jax314`;
their working CPU workflows remain in `jax`. This is not an exact clone of
the TensorFlow stack. TensorFlow Probability's JAX substrate is a separate
capability from TensorFlow execution.

## Verified result

The final `jax314` inventory contains 193 packages, versus 196 in `jax`.
Every shared package version matches exactly; there are no additional packages.
Only TensorFlow, TF-Keras and GPflow are omitted. Local editable project links
were preserved. h5py 3.14.0 and rpy2-rinterface 3.6.6 built for Python 3.14.

The dependency check is clean. Runtime checks passed for GPU JAX float64
linear algebra and gradients, BlackJAX HMC, NumPyro NUTS, CPU PyTorch linear
algebra, an HDF5 write/read round trip, Numba-compiled LAPACK, PyTensor's NUMBA
backend, and a compiled PyMC model. The installed Flax, Optax, Diffrax, Lineax
and Optimistix modules imported successfully. These checks do not constitute
full regression testing of every library or project.

## Final maintenance of the existing environment

Nutpie updated to 0.16.11. PyGAM requires SciPy below 1.17, TensorFlow requires
h5py below 3.15, and the retained CPU PyTorch requires setuptools below 82.
After checking the proposed upgrades, SciPy 1.16.3, h5py 3.14.0 and setuptools
81.0.0 were retained. The final `jax` dependency check reports only GPflow's
previously documented NumPy constraint. GPflow 2.11.1 still declares `numpy<2`,
so it was not installed as a compatible upgrade.

The default `py313` environment retains older docutils, mpmath and
pydantic-core versions selected by its dependency constraints. Those packages
were included in the earlier full upgrade resolution. An outdated-package
listing alone is not a reason to override those constraints.
